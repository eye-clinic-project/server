7. Analysis / AI Module
Base URL: /api/v1/analyses

ده أهم Module في المشروع، وهو اللي بيتعامل مع FastAPI.
Method	Endpoint	الوصف
POST	/analyses	إنشاء تحليل جديد لصورة
POST	/analyses/:analysisId/predict	إرسال الصورة لخدمة AI لعمل Prediction
GET	/analyses	عرض التحاليل
GET	/analyses/:analysisId	تفاصيل تحليل معين
GET	/analyses/:analysisId/result	نتيجة الـ Prediction
GET	/analyses/:analysisId/grad-cam	عرض Grad-CAM Heatmap
GET	/analyses/:analysisId/history	سجل التحليل
POST	/analyses/:analysisId/retry	إعادة التحليل عند فشل العملية
DELETE	/analyses/:analysisId	حذف التحليل حسب الصلاحيات

الـ Prediction بيرجع معلومات زي:
{
  predictedLevel: 0 | 1 | 2 | 3 | 4,
  confidence: number,
  gradCamUrl: string,
  modelVersion: string
}


الـ Severity Levels:
Level	الحالة
0	No DR
1	Mild
2	Moderate
3	Severe
4	Proliferative DR
